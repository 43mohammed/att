# نظام الحضور والغياب الذكي 📚

تطبيق PWA متكامل لتسجيل حضور الطلاب باستخدام QR Code و NFC مع دعم كامل للعمل بدون اتصال بالإنترنت.

## المميزات الرئيسية ✨

### 1. نظام مصادقة متعدد الأدوار
- **المسؤول (Admin)**: إدارة النظام والمستخدمين والمقررات
- **المحاضر (Instructor)**: تفعيل جلسات الحضور ومراقبة السجلات
- **الطالب (Student)**: مسح QR Code وعرض سجل الحضور

### 2. تسجيل الحضور الذكي
- **مسح QR Code**: توليد رموز QR ديناميكية تتجدد تلقائياً
- **دعم NFC**: قراءة بطاقات NFC للتحقق من الهوية
- **التحقق من GPS**: التأكد من تواجد الطالب في الفصل الدراسي
- **منع الغش**: رموز فريدة لكل جلسة مع تسجيل الوقت والموقع

### 3. لوحات التحكم المتخصصة
- **لوحة المسؤول**: إدارة المستخدمين والمقررات والجداول
- **لوحة المحاضر**: إنشاء جلسات وعرض الحضور الفوري
- **لوحة الطالب**: عرض السجل والإحصائيات والإشعارات

### 4. التقارير والإحصائيات
- تقارير يومية وأسبوعية وشهرية
- تصدير إلى PDF و Excel
- إحصائيات الحضور والغياب
- تنبيهات عند اقتراب حد الغياب المسموح

### 5. ميزات PWA
- **العمل بدون اتصال**: حفظ البيانات محلياً والمزامنة عند الاتصال
- **Service Worker**: تخزين مؤقت ذكي للملفات
- **تثبيت التطبيق**: تثبيت التطبيق على الهاتف كتطبيق أصلي
- **إشعارات فورية**: تنبيهات بشأن الحضور والغياب

## البنية التقنية 🏗️

### Backend
- **Laravel 11**: إطار عمل PHP قوي
- **SQLite**: قاعدة بيانات خفيفة الوزن
- **RESTful API**: واجهات برمجية حديثة

### Frontend
- **HTML5**: معايير الويب الحديثة
- **CSS3**: تصميم سريع الاستجابة
- **JavaScript Vanilla**: بدون مكتبات خارجية ثقيلة
- **Service Worker**: دعم PWA

### قاعدة البيانات
```
users (المستخدمون)
├── courses (المقررات)
│   ├── enrollments (التسجيل)
│   ├── attendance_sessions (جلسات الحضور)
│   │   └── attendance_records (سجلات الحضور)
│   ├── notifications (الإشعارات)
│   └── reports (التقارير)
└── audit_logs (سجلات التدقيق)
```

## التثبيت والتشغيل 🚀

### المتطلبات
- PHP 8.1+
- Composer
- Node.js (اختياري)

### خطوات التثبيت

1. **استخراج المشروع**
```bash
unzip attendance-system.zip
cd attendance-system
```

2. **تثبيت المكتبات**
```bash
composer install
```

3. **إنشاء ملف البيئة**
```bash
cp .env.example .env
php artisan key:generate
```

4. **إنشاء قاعدة البيانات**
```bash
touch database/attendance.sqlite
php artisan migrate
```

5. **تشغيل السيرفر**
```bash
php artisan serve
```

6. **الوصول للتطبيق**
```
http://localhost:8000
```

## استخدام التطبيق 📖

### للطالب
1. قم بتسجيل الدخول بحسابك
2. اذهب إلى "مسح QR Code"
3. امسح رمز QR الذي يعرضه المحاضر
4. سيتم تسجيل حضورك تلقائياً

### للمحاضر
1. قم بتسجيل الدخول
2. اختر المقرر
3. انقر على "بدء جلسة حضور"
4. اعرض رمز QR للطلاب
5. راقب الحضور الفوري
6. انقر على "إغلاق الجلسة" عند الانتهاء

### للمسؤول
1. قم بتسجيل الدخول
2. استخدم لوحة التحكم لإدارة:
   - المستخدمين
   - المقررات
   - الجداول الدراسية
   - عرض التقارير
